# NeuroMedia 新闻视频交接样片设计规格

## 目标

将 NeuroMedia 从“记者直接制作短视频的工具”重新定位为“新闻视频交接样片生成器”。

记者输入文字报道和现场图片/视频素材后，系统快速生成一条可播放的视频交接样片，并同步生成结构化分镜表。记者通过 CUI Agent 用自然语言修改表达意图，最后将视频样片和分镜表交给编导或 AI 视频制作人员继续完成专业成片。

## 产品定位

NeuroMedia 服务的是新闻生产链路中的交接环节，而不是替代完整后期制作。

核心价值：

- 帮记者把文字报道翻译成视频表达方向。
- 帮编导快速理解记者想要的节奏、重点、素材使用和画面意图。
- 降低记者学习视频制作工具、时间线、镜头语言和 AI 生成参数的成本。

一句话定位：

`把新闻报道和现场素材，生成一条给制作人员看的视频交接样片。`

## 目标用户

主要用户是无视频制作经验或经验较少的新闻工作者，包括记者、通讯员、采编人员和新媒体编辑。

他们通常具备：

- 对新闻事实、现场背景和报道重点有强掌控。
- 对视频剪辑、分镜、镜头运动、节奏控制和 AI 视频参数不熟。
- 希望快速把“我想要这个报道怎么变成视频”表达给后续制作人员。

次要用户是编导、视频编辑和 AI 视频制作人员。他们接收交接样片和分镜表，用来快速理解需求并继续制作。

## 用户痛点

记者无法快速上手视频制作工具，主要不是因为缺少功能，而是因为任务语言不匹配。

典型问题：

- 视频工具要求用户理解时间线、轨道、转场、镜头、画幅、字幕和配乐。
- AI 视频工具要求用户写视觉提示词，但记者更习惯写事实、背景和采访信息。
- 生成结果不可控，记者担心事实被改写、画面误导真实新闻现场。
- 记者缺少时间学习专业剪辑流程，制作短视频常常不是其核心岗位职责。
- 与编导沟通时，文字报道无法充分表达视频节奏、画面优先级和情绪方向。

## 设计原则

1. 以视频样片为主，而不是以分镜工作台为主。
2. 让记者修改“表达意图”，不要让记者学习剪辑工具。
3. 每次 Agent 修改都要映射到具体镜头、素材或分镜字段，避免黑箱改动。
4. 分镜表只保留交接所需字段，不暴露过多专业参数。
5. 交接包保持克制，只包含视频样片和结构化分镜表。
6. 明确样片是制作沟通用途，不是最终发布成片。

## 新主流程

```text
报道 + 素材
-> 生成视频交接样片
-> CUI Agent 修改表达意图
-> 导出交接包
```

不再提供“快速成片 / 可编辑草稿”两个入口。系统默认生成可播放样片，并保留分镜表作为交接依据。

## 页面 1：输入页

页面标题：

`生成视频交接样片`

输入页只保留一个主任务，不让用户先选择制作模式。

核心区域：

- 报道输入框：粘贴新闻报道、采访稿、通稿或简短想法。
- 素材上传区：上传现场图片和视频。
- 可选意图输入：一句话说明想要的表达方向，例如“突出人物温情”“做成严肃新闻短片”。
- 主按钮：`生成交接样片`。

输入页不默认展示风格、画幅、分镜模式、自动生图策略等专业选择。

## 页面 2：生成过程

生成过程应展示系统正在进行的工作，减少黑箱感。

建议状态：

- 正在提炼新闻主线
- 正在识别可用素材
- 正在规划视频结构
- 正在生成视频样片
- 正在整理分镜表

这些状态服务于建立信任，不应变成复杂配置。

## 页面 3：视频交接样片页

这是新流程的核心页面。

建议布局：

```text
左侧/中间：视频样片播放器
右侧：CUI Agent
下方：结构化分镜表
```

### 视频样片

视频样片是第一优先级产物。记者进入结果页后，应先能播放、感受节奏和画面方向。

样片可以是低保真，但必须表达清楚：

- 使用上传图片和视频素材。
- 图片自动加入基础推拉、裁切和转场。
- 自动生成字幕和临时旁白节奏。
- 缺素材的镜头可用 AI 参考画面或占位画面。
- 画面应标注来源，例如“现场素材”“AI 参考画面”“待制作”。
- 页面或视频上应明确标注：`制作沟通样片，非发布成片`。

### 结构化分镜表

分镜表是给制作人员看的交接依据，不是让记者填写的复杂表单。

默认字段：

| 镜头 | 画面意图 | 字幕/旁白 | 素材来源 | 制作备注 |
| --- | --- | --- | --- | --- |

字段说明：

- 镜头：镜头编号和预计时长。
- 画面意图：这段画面承担什么叙事功能。
- 字幕/旁白：对应的文字表达。
- 素材来源：用户上传素材、AI 参考画面、待补素材。
- 制作备注：给编导的简短说明，如“建议替换为现场视频”“此处不要使用 AI 生成真实人物画面”。

专业参数如提示词、焦距、镜头运动、画幅等默认不展示，可在高级编辑中折叠查看。

## CUI Agent 设计

Agent 是视频交接样片的意图编辑器，不是普通聊天框。

它承担三件事：

1. 生成前确认表达目标。
2. 生成后帮助记者审片。
3. 修改时把自然语言映射到播放器、分镜表和素材引用。

### 生成前：确认意图

上传报道和素材后，Agent 自动读内容，并用非专业语言复述理解。

示例：

```text
我理解这条报道适合做成一条 40 秒左右的温情纪实样片。
重点是“广州家庭味道和代际记忆”，优先使用你上传的现场图片。
AI 画面只用于补充缺失镜头。可以按这个方向生成吗？
```

用户可以点击快捷调整：

- 更像新闻报道
- 更有人情味
- 更短，30 秒内
- 只用现场素材
- 允许少量 AI 参考画面
- 先给编导看，不追求成片精致

如果信息不足，Agent 只问一个最必要的问题，例如：

```text
这条样片更想突出“事件信息”，还是“人物情绪”？
```

不问“镜头语言”“转场风格”“配乐类型”等制作术语。

### 生成后：审片助手

样片生成后，Agent 主动给出审片摘要。

示例：

```text
我做了一条 38 秒交接样片：
开头用现场图建立情绪，中段解释事件背景，结尾回到人物温情。
目前第 3 镜头缺少真实素材，用了 AI 参考画面，建议制作人员后续替换。
```

常用修改按钮：

- 开头更抓人
- 更像正式新闻
- 减少 AI 画面
- 缩短 10 秒
- 强化现场素材
- 重写字幕
- 调整结尾情绪
- 检查分镜表

### 修改时：可视化确认

Agent 每次执行修改前，应先展示影响范围，让用户确认。

用户输入：

```text
第三个镜头不要 AI 画面，换成我上传的那张厨房图。
```

系统行为：

1. 高亮分镜表第 3 行。
2. 高亮素材库里的目标图片。
3. 在 Agent 中显示修改预览。

示例预览：

```text
将修改：
镜头 3
画面来源：AI 参考画面 -> 上传素材「厨房_奶奶端汤.jpg」
字幕保持不变
时长保持 5s
```

操作按钮：

- 确认修改
- 换一张素材
- 取消

确认后：

- 视频样片更新。
- 分镜表第 3 行更新。
- Agent 对话中保留修改记录。

## Agent 与界面元素联动

### 与播放器联动

- 视频播放到某个镜头时，对应分镜行高亮。
- 用户在播放器时间点暂停并输入修改，Agent 自动带入当前镜头上下文。
- Agent 修改完成后，可以跳转播放修改过的片段。

### 与分镜表联动

- 点击分镜表某一行，Agent 进入“针对这个镜头修改”的上下文。
- 输入框提示变为：`正在修改镜头 2，可以说“换素材”“字幕短一点”“多停留 2 秒”...`
- Agent 修改分镜字段前先展示预览。
- 分镜表是 Agent 的操作对象，不是静态结果展示。

### 与素材联动

- 素材可以被标记为“必须使用”“仅作参考”“不使用”。
- 当用户提到“这张图”“那段视频”时，Agent 尝试映射到具体素材；不确定时让用户选择。
- 素材来源变化会同步反映到视频样片和分镜表。

## 交接包

交接包保持极简，只包含两个产物：

1. 视频交接样片
2. 结构化分镜表

建议 MVP 导出格式：

- 视频样片：MP4
- 分镜表：PDF

后续可增加 Markdown、Excel 或项目文件，但 MVP 不引入。

## 现有功能迁移

### 取消默认双模式入口

移除或隐藏“快速成片 / 可编辑草稿”作为记者入口。它们不符合记者的任务模型。

### 分镜工作台降级为高级入口

现有分镜工作台保留给制作人员或高级用户使用，但不作为记者默认主界面。

推荐新层级：

- 默认：视频样片 + Agent + 分镜表。
- 高级：完整分镜工作台。

### 现有能力复用

可以复用现有能力：

- 报道解析和方案生成。
- 素材上传、选择和引用。
- 分镜生成。
- 图像生成和图生视频能力。
- AI Director/Assistant 的动作解析能力。
- 导出能力。

但交互入口和信息架构需要围绕“样片交接”重组。

## MVP 范围

MVP 应优先实现以下闭环：

1. 输入报道和素材。
2. 生成视频样片。
3. 生成结构化分镜表。
4. CUI Agent 支持全局修改和单镜头修改。
5. Agent 修改前显示影响范围并等待确认。
6. 导出 MP4 样片和 PDF 分镜表。

暂不做：

- 完整专业剪辑时间线。
- 多人实时协作。
- 复杂镜头参数编辑。
- 多版本项目管理。
- 发布平台适配自动投放。

## 成功标准

对记者：

- 不需要学习剪辑工具，也能在 3 分钟内生成一条可播放交接样片。
- 能用自然语言说明修改意见。
- 能看懂哪些画面来自现场素材，哪些是 AI 参考或待制作。

对制作人员：

- 打开交接包后能理解视频结构、镜头意图和素材来源。
- 能基于样片和分镜表继续制作，不需要反复追问记者“你想要什么效果”。

对产品：

- 首页不再让新手理解制作模式。
- 结果页第一视觉中心从分镜卡变为视频样片。
- Agent 修改不是黑箱聊天，而是可确认、可定位、可回溯的界面操作。

## MVP 默认决策

1. 视频样片需要在页面内可播放，并支持导出 MP4。交接包导出按钮在 MP4 未准备好时显示生成进度，不导出半成品。
2. 分镜表 PDF 只包含项目标题、导出时间、分镜表和必要说明，不默认加入机构 logo。
3. Agent 修改优先局部更新受影响镜头，再刷新整体视频预览；只有涉及全片节奏、时长或风格时才重生成整条样片。
4. AI 参考画面必须在视频样片和分镜表中标注，避免被制作人员误认为真实现场素材。
