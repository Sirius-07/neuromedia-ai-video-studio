# NeuroMedia 新手视频制作流程 UX 优化方案

## 目标

让没有视频制作经验的用户，也能看懂 NeuroMedia 的完整创作流程，并顺利完成：

`输入内容 -> 选择视频方案 -> 检查脚本 -> 选择画幅和风格 -> 生成分镜 -> 继续生成画面/视频`

本次优化不改变后端核心业务逻辑，重点调整页面结构、信息架构、中文文案、交互层级和移动端布局。

## 当前主要体验问题

1. 入口页定位太像“新闻处理后台”，新手不一定知道这里可以直接开始做短视频。
2. 顶部流程存在，但用户不容易理解自己当前在哪一步、下一步会发生什么。
3. 多处关键按钮和状态仍是英文，例如 `ADD SHOT`、`CHOOSE STYLE`、`AI Director`，会增加新手理解成本。
4. 方案选择弹窗信息过密，新手在还没理解方案差异前，就被 5W1H、来源依据、标签、分镜预览等信息同时轰炸。
5. 脚本页和分镜页过早暴露专业参数，比如镜头、焦距、设备、视角等，新手第一眼容易不知道该改哪里。
6. AI 助手在部分宽度下会挤压主内容，移动端尤其明显。
7. 移动端存在按钮换行、输入框内部滚动、标题被挤成竖排等界面问题。

## 总体改法

采用“引导式创作”的信息架构：

- 每个页面只强调当前这一步最重要的任务。
- 专业控制项默认收起，放到“高级参数”或辅助区域里。
- 主按钮全部改成明确动作，例如“生成视频方案”“选这个方案，生成脚本”“生成分镜”。
- 顶部流程条用中文步骤标识，让用户知道当前进度。
- AI 助手在移动端改成浮层抽屉，不再挤压正文。
- 所有核心页面都保证桌面和移动端不横向溢出。

## 页面级修改方案

### 1. 入口页

文件：

- `frontend/src/components/StartPage.tsx`

修改点：

- 将页面定位从“新闻稿处理台”改成“开始制作短视频”。
- 输入模式改成“粘贴文稿 / 输入想法”和“上传图片 / 视频素材”。
- 输入框 placeholder 改成面向新手的示例说明。
- 主按钮空态显示“先输入内容”，可点击后显示“生成视频方案”。
- 支持“快速成片”和“可编辑草稿”两个目标选择。
- 底部说明卡改为“自动整理重点”“保留来源依据”“适合短视频发布”。
- 修复移动端输入框空态出现内部滚动条的问题。

预期效果：

新用户进入首页后，能立刻知道自己可以粘贴文稿、输入想法或上传素材来开始制作短视频。

### 2. 方案选择弹窗

文件：

- `frontend/src/components/InspirationModal.tsx`

修改点：

- 弹窗标题改为“选择一个视频方案”。
- 方案卡片减少首屏信息密度，只保留标题、适用场景、关键标签和摘要。
- 详细事实、来源、5W1H、完整分镜列表放到次级信息里。
- 底部按钮改成“返回修改”和“选这个方案，生成脚本”。
- 错误状态只显示一个明确失败提示，并提供“重试生成”。

预期效果：

用户能先快速比较方向，而不是一开始就被专业信息淹没。

### 3. 顶部工作台导航

文件：

- `frontend/src/components/studio/StudioApp.tsx`

修改点：

- 顶部步骤改成中文：“脚本”“风格”“分镜”。
- 项目菜单改成“项目”，并修复窄宽度下拆成两行的问题。
- 在非首页显示当前步骤说明：
  - 第 1 步：检查脚本
  - 第 2 步：选择画幅和风格
  - 第 3 步：生成分镜画面
- 移动端顶部导航允许换行排列，不挤压主内容。

预期效果：

用户能清楚知道自己在流程中的位置，不需要理解英文制作术语。

### 4. 脚本页

文件：

- `frontend/src/components/ScriptEditorPage.tsx`

修改点：

- 将 `SHOTS` 改为“个分镜”。
- 将 `ADD SHOT` 改为“添加分镜”。
- 将 `BACK` 改为“返回”。
- 将 `CHOOSE STYLE` 改为“选择风格”。
- 将 `AI Co-writer` 改为“AI 改稿助手”。
- 将 `GLOBAL` / `SHOT N` 改为“全局” / “分镜 N”。
- 修复桌面窄宽度下“5 个分镜”“添加分镜”换行问题。
- 修复移动端标题被挤成竖排的问题。
- 移动端 AI 改稿助手改为浮层抽屉，避免挤压脚本正文。

预期效果：

脚本页更像“检查和微调脚本”，而不是专业剪辑后台。移动端可以正常阅读和操作。

### 5. 风格选择页

文件：

- `frontend/src/components/StyleSelectionPage.tsx`

修改点：

- 页面说明改成“先选发布比例，再选画面风格。之后 AI 会生成分镜图。”
- 底部状态改成中文：
  - 请选择画幅和风格
  - 已选画幅，还需选择风格
  - 已选风格，还需选择画幅
  - 已选好，可以生成分镜
- CTA 改成“生成分镜”。
- 修复移动端底部按钮布局。

预期效果：

用户知道这里不是最终生成视频，而是为分镜生成确定画幅和画面风格。

### 6. 分镜页

文件：

- `frontend/src/components/storyboard/VisualStoryboardPage.tsx`
- `frontend/src/components/storyboard/assistant/StoryboardDirectorPanel.tsx`
- `frontend/src/components/storyboard/assistant/StoryboardActionPreview.tsx`

修改点：

- 分镜卡片默认只展示“画面内容”等新手最关心的信息。
- 镜头、视角、设备、焦距等专业字段收进“高级镜头参数”。
- 主按钮改成“先生成分镜画面”。
- `AI Director` 改为“AI 分镜助手”。
- `IMAGE` / `VIDEO` 改为“图片” / “视频”。
- `Shot N` 改为“分镜 N”。
- 移动端 AI 分镜助手保持浮层，不挤压分镜卡片。
- 修复桌面和移动端横向溢出。

预期效果：

新手先看懂“这一镜画面是什么”，再决定是否展开专业参数调整。
